## What `/new-game` is

A **workflow entry point**, a new binding surface kind (`workflows:` in
`core/bindings/adapter-binding.yaml`), not a transition. `/web-game-factory:new-game` (and the
Codex adapter's `commands/new-game.md`) starts or resumes a run of
`core/workflows/new-game.workflow.yaml` through the existing engine — `bin/wgf new-game` /
`bin/wgf resume`, in the background — and reports it from `bin/wgf status`. The workflow file
stays the only step order, retry, loop, gate and resume logic; the command restates none of
it and composes no `/wgf-*` command.

```
/new-game  →  bin/wgf new-game (workflow engine)  →  core/workflows/new-game.workflow.yaml
/wgf-*     →  one lifecycle transition each (unchanged)
```

It never answers a gate. `wgf decide` and `resume --decision` run from the agent session would
be recorded as a person's decision (`default_decider()` sees no step process tree), so the
command refuses `--decision`, `--note`, `decide` and `--budget-*`, and at every gate or develop
handoff stops with the command the person types. It reports the configured autonomy without
changing `factory.yaml`, and asks before a real run whose init creates a GitHub repository.
`disable-model-invocation: true`: only a person starts one.

With the shipped `factory.yaml` a real run still waits at G2, G3 and the develop handoff,
and release refuses an unreviewed build. Unattended execution up to G4 is installation
config ([claude-capabilities.md](claude-capabilities.md)); G4 is always a person's.

## Why the Factory release is minor

One new adapter surface; no engine, workflow, lifecycle, gate, schema, configuration key or
template-contract change. The 13 `/wgf-*` commands, the agents and the skills regenerate
byte-identical. `check-integrity.py` gains a check of each `workflows:` entry against its
workflow file; nothing that passed before fails.

## What this release does not cover

- **No real (non-mock) run through `/new-game`.** The entry point was exercised end to end on
  the mock engine, in real headless Claude Code sessions; a real run is the engine's, which
  this release does not change.
- **The interactive shorthand `/new-game`** was not exercised; headless `claude -p` resolves
  only the namespaced `/web-game-factory:new-game`, for every command of this plugin.
- A headless session ends before a background run's exit notice arrives; interactive
  sessions receive it.
